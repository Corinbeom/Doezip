## 구현

작성한 보고서의 자동 저장이 끝나면 최초 제출을 명시적으로 확인한다. 서버 저장 응답의 버전과 SHA-256으로
스냅샷을 생성하고 즉시 봉인한다. 최초 제출본과 세션의 WRITING → CHALLENGE 전환은 한 트랜잭션이다.
현재는 검산 대기 상태이며 status는 ACTIVE다. 검산·평가·학습 완료로 표시하지 않는다.

POST/GET `/api/v1/sessions/{id}/document-versions`는 인증한 소유자만 사용할 수 있고 다른 사용자는 404다.
본문·해시·원본 저장 버전·봉인 시각을 이력 조회에서 반환한다. Entity를 HTTP 응답으로 사용하지 않는다.
동일 요청은 이미 생성된 제출본을 201로 반환한다. 다른 입력의 INITIAL 중복은 409이며 새 학습 시도를 시작해야 한다.
버전/해시 불일치와 잘못된 단계는 409, 빈 본문은 422다. FINAL은 아직 사용할 수 없다.

초안 저장과 같은 세션 행 잠금을 사용해 저장과 제출의 경쟁을 막는다. V7은 document_versions만 추가하며
INITIAL의 세션당 유일성, 세션 내 버전 유일성, UPDATE 금지 트리거를 둔다. 기존 migration은 변경하지 않는다.
전체 도메인 테이블은 6개이며 22개 ERD 전체나 학습용 seed 구현 완료를 뜻하지 않는다.

제출 중에는 편집을 잠그고 결과를 보여준다. 실패/응답 유실은 성공으로 표시하지 않으며 재시도·제출본 확인을 제공한다.
충돌한 로컬 내용은 보존하고 사용자 확인 후 서버 저장본을 불러온다. 제출본은 원문 텍스트로만 표시하고 HTML·링크를 실행하지 않는다.
개인 Query는 사용자 ID로 분리하고 계정 변경 시 요청·편집기를 정리한다. 검산 초안·비공개 정답을 포함하지 않는다.
