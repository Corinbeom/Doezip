# P02 — 단계형 작업 공간과 훈련 안내

## 확정한 동작 기준

P01의 첫 흐름을 이어받는다. 훈련은 과제 이해·작업·검증 시점마다 접근 방법과 점검 질문을 제공한다. 모의 전형은 같은 목표·요구사항·제출 조건·작업 AI를 제공하되 과정 코칭과 선택 힌트는 제공하지 않는다. 시간제한·감독·점수 차등을 도입하지 않는다. 과제 이해 안내는 기본 펼침, 작업·검증 안내는 편집 공간을 확보하도록 기본 접힘으로 제공한다. 안내는 고정된 학습 지원이며 사용자의 행동을 분석한 AI 코칭이라고 표시하지 않는다.

| 단계 | 해야 할 일 / 남는 기록 | 이동·수정 |
| --- | --- | --- |
| 과제 이해 | 상황·요구사항·제출물 읽기. 훈련은 접근 방법 안내 | 제출 전 자유 이동, 읽음으로 역량 판정하지 않음 |
| 작업 | AI와 대화, 보고서·코드 편집, 자료 대조·테스트 | 자료·AI·결과물 패널 이동 시 버퍼 유지. 보고서 자동 저장, 코드 명시적 저장 |
| 검증·제출 | 채택 이유·한계·확인 방법·선택 인용 작성 | 명시적 저장. 작업으로 복귀 가능. 제출은 확인창을 거쳐 서버에서 봉인 |
| 직접 설명 | 두 질문에 자기 생각을 답하고 확정 | AI 패널 없음. 제출물 읽기 전용. 확정 전 새로고침은 답변 복원하지 않음 |
| 피드백 | 실제 고정 기록과 피드백 확인, 새 재연습 생성 | 기존 제출본 변경 불가. 새 재연습에서 작업 재개 |

제출 가능 조건은 P01과 동일하다. 최신 표시 결과물 저장 완료, 진행 중 AI 없음, 코드 현재 버전 테스트 기록, 두 검증 설명이 필요하다. 테스트 통과·힌트 열람·안내 완독을 강제하지 않는다. 관찰 기록·평가 API·프롬프트·DB는 변경하지 않는다. 화면 안내를 읽었다고 실제 검증 행동을 추가 기록하지 않는다.

## 화면 기준

작업 단계에 자료·AI와 결과물을 좌우로 배치한다. 작은 화면에서는 탭을 사용한다. 패널은 숨길 때 unmount하지 않으므로 미저장 코드·질문·설명과 패널 스크롤 위치를 유지한다. 새로고침 복원은 서버 저장 데이터만 보장한다. 제출 전 새로고침 시 과제 이해 화면에서 시작하며, 서버의 WORKING/EXPLAIN/FEEDBACK 단계는 유지된다. 단계 전환은 짧은 좌우 효과와 키보드 가능한 명시적 버튼을 사용하며 휠을 가로 이동으로 가로채지 않는다. reduced-motion에서는 효과를 생략한다. 제목과 이동 버튼은 작업 공간 위에 유지한다.

## 작업 분리와 실행

`feature/P02-guided-workspace`는 origin/develop에서 분기 후 I02·P01을 의존성으로 가져온다. P02 변경은 UI·회귀 테스트·문서에 한정한다. 원본 F00/P01은 수정하지 않는다. 사용자 확인 주소는 3189, API 8389, PostgreSQL 55609의 doezip_preview로 유지한다. 검증은 별도 포트와 PostgreSQL 55629의 doezip을 사용한다. push/PR/merge/배포는 수행하지 않는다.
