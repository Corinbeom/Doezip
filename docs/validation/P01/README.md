# P01 실제 AI 검증 기록

2026-09-15 UTC 11:17:48 시작. `npm run test:learning:ai`로 공개 가상 사례 4개를 각 1회 호출했다. 사용자 데이터·비공개 정답·OAuth·DB는 사용하지 않는다. `live-v1/`은 입력과 반환 후보 원문이다. `sha256.json`으로 무결성을 확인한다. 원문을 성공 응답으로 교정하지 않았다.

- 보고서/구현 × 근거 있는 수행/기록이 부족한 수행을 구분한 4개 사례.
- 구조·근거 ID·원문 복원 및 내부 용어 검사 4/4 통과. 이전 F05d 검증과 별개다.
- 기록이 부족한 사례는 관찰의 한계를 설명했고, 미완성 구현에서는 중복 처리와 입력 변경 문제를 지적했다. 브라우저 테스트 기록을 독립 채점 점수로 표시하지 않았다.
- 에이전트 내용 검토: `report-grounded.json` VERIFY nextAction의 “제안받은 추가 확인 방법”은 입력에 AI 제안 기록이 없어서 제안 주체를 추정하게 하는 표현이다. 확인 방법 자체는 사용자 보고서에 있으나 누가 제안했는지 단정할 근거는 없다. 구조/ID 검증으로 잡히지 않는 귀속 표현 문제로 남긴다.
- 따라서 실제 공급자 연결과 구조 검증 통과를 전체 평가 품질 승인으로 표시하지 않는다. 제안 주체·행동 출처의 정확성, 더 긴 대화/실패 수정 과정, 전문가 콘텐츠 검수가 후속이다. 추가 프롬프트 반복 호출로 이번 결과를 지우지 않았다.
