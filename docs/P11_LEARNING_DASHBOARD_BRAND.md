# P11 내 학습 대시보드와 브랜드 적용

## 화면 역할

- `/tasks`는 새 과제를 탐색하고 연습 방식을 선택하는 곳이다.
- `/learn`은 진행 중인 학습을 이어가고, 완료한 결과물과 피드백 리포트를 다시 보는 개인 기록 화면이다.
- 랜딩 페이지의 시작 행동은 `/tasks`로 연결한다.

`/learn` 안에 과제 카탈로그를 중복 표시하지 않는다. 진행 기록이 없는 경우와 화면 하단에서만 과제 둘러보기로 안내한다.

## 완료 기록

완료한 과제는 접힌 목록 대신 바로 확인할 수 있는 카드로 표시한다. AI 피드백이 완료된 기록에는 다음 연습의 집중 영역과 대표 관찰을 함께 보여주고, 전체 결과물과 피드백은 기존 상세 화면에서 확인한다.

이전 버전에서 제출한 스냅샷은 저장 당시 내용 그대로 보존한다. 과제 카탈로그 메타데이터가 추가되기 전에 저장된 기록은 목록·상세 응답을 만들 때 해당 콘텐츠 버전의 식별자, 난도, 예상 시간과 태그를 보강한다. 이 과정에서 DB의 봉인된 스냅샷이나 당시 제목·본문은 변경하지 않는다.

## 브랜드 자산

사용자가 제공한 되짚 로고와 심볼을 제품 자산으로 사용한다.

- `apps/web/public/brand/doezip-wordmark.svg`: SUIT ExtraBold를 사용한 가로형 워드마크. 제품 헤더와 푸터에서 사용
- `apps/web/public/brand/doezip-symbol.png`: 재사용 가능한 원본 심볼
- `apps/web/src/app/icon.png`: Next.js 앱 아이콘

로고는 장식용으로 중복 읽히지 않도록 빈 대체 텍스트를 사용하고, 홈 링크에는 목적을 설명하는 접근성 이름을 유지한다.
헤더에서는 데스크톱 `96×41px`, 모바일 `84×36px`, 푸터에서는 `80×34px`로 표시한다. 앱 아이콘은 흰 배경의 `400×400px` PNG를 사용한다.
