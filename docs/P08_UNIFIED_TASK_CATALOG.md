# P08 — 통합 과제 카탈로그

## 범위

- `/tasks`에서 현재 보고서·구현 과제를 함께 보여 준다.
- 공개 catalog 응답에 `catalogId`, 콘텐츠 `version`, 유형, 난도, 예상 시간, 태그를 포함한다.
- 카드에서 유형을 필터링하고 상세에서 과제 상황, 완료 조건, 제출물을 확인한다.
- 로그인 사용자는 상세에서 훈련·모의 전형을 선택해 실제 `/learn/{id}` 흐름을 시작한다.
- 주 메뉴의 독립 `구현 연습` 진입은 제거한다. 기존 `/coding`과 `/coding/{id}`, UUID 기반 이전 과제 상세는 저장 흐름 호환을 위해 직접 URL에서 유지한다.
- 공개 catalog는 힌트나 비공개 정답을 반환하지 않는다. 작업 생성·개인 기록 API는 계속 인증과 소유권 검사를 적용한다.

## 후속 범위

P09에서 catalogId와 콘텐츠 version을 실제 생성 요청과 저장 기록까지 연결했다. P10에서 실무형 보고서·구현 과제를 하나씩 추가해 공개 카탈로그는 네 개 과제를 제공한다. 숨은 테스트, 다른 언어·다중 파일 실행, 기업 문제 빌더는 후속 문제 품질 고도화에서 다룬다.
