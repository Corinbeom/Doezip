# 디자인 토큰 기준

[승인 원본](../README.md)의 styles.css를 따른다. 토큰을 별도 제품 테마로 재해석하지 않는다.

| 역할 | 기준 |
|---|---|
| 배경 / 표면 | #f7f8f5 / #ffffff |
| 본문 / 보조 텍스트 | #24342d / #647169 |
| 주요 액션 / hover | #255846 / #1b4536 |
| 강조 / 옅은 초록 | #d5e9a7 / #eaf0e5 |
| 경계 / 보조 배경 | #e0e5dd / #f1f4ee |
| 오류 | #a73f31 |
| 기본 서체 | 시스템 sans-serif, Apple SD Gothic Neo, Noto Sans KR, Malgun Gothic |
| 기본 본문 | 15px, 줄 높이 1.65 |
| 형태 | 둥근 카드·패널, 데스크톱 2열, 모바일 1열 |

서체는 로컬 시스템 폰트를 사용하며 외부 폰트 요청이나 새 의존성을 추가하지 않는다.
제목·본문 위계, 충분한 버튼 높이, 키보드 포커스와 모바일 가로 넘침을 검증한다.
