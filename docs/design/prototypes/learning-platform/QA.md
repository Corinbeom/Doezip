# 학습 플랫폼 시안 — 확인 기록

확인일: 2026-09-07 · 대상: `http://127.0.0.1:4387/`

## 기존 제작 시점의 검증 기록

아래 내용과 screenshots/의 14장은 원본 시안에서 전달받은 기존 기록이다. 별도 worktree에서 새로 수행한 검증은 문서 끝의 별도 항목으로 구분한다.

### 결과

독립 디자인 시안의 주요 학습 흐름을 실제 브라우저에서 처음부터 끝까지 수행했다. 입력·원문 근거·최초 및 최종 보고서는 직접 조작한 내용으로 확인했다. 이 결과는 실제 제품 API·AI 평가·로그인·배포의 동작 검증을 의미하지 않는다.

사용 브라우저: Codex In-app Browser. 데스크톱 1440×1000, 작은 데스크톱 1280×900, 모바일 390×844로 검토했다.

일반 입력과 모든 안내 메시지를 스크린리더로 전수 확인한 것은 아니다. 장문 수만 자, 브라우저 저장소 차단·용량 초과, 여러 탭 동시 편집, 다른 브라우저 엔진은 미검증이다.

검토 중 전체 화면이 상태 변경마다 잠시 흐려지는 동작을 없애고, 본문 바로가기가 학습 화면을 벗어나지 않게 수정했다. 저장한 검토를 재편집할 때 진행 건수도 즉시 갱신하도록 보완했다.

초기 파일 내보내기는 내장 브라우저에서 다운로드 이벤트를 확인할 수 없어 제거했다. 최종 시안은 전체 기록 모달과 선택·복사 방식으로 제공하며, 실제 기록 전체 선택을 확인했다. 클립보드 복사 단축키 실행은 사용자에게 맡긴다.

캡처는 `screenshots/`에 저장했다. 전체 페이지 캡처가 아니라 주요 영역의 뷰포트 캡처다. 검사 때 사용한 가상 입력은 마지막에 시안 UI에서 초기화하여, 사용자가 첫 문제부터 경험할 수 있도록 했다.

## 저장소 전체 검사 — 별도 결과

실제 제품 코드도 함께 변경한 것으로 오해하지 않도록 독립 시안 검증과 구분한다. 저장소 규칙의 `npm run check`를 기존 Node 24.20.0 경로로 실행했다.

- 통과: OpenAPI 검증, 공개 fixture 21개 검증, API 타입 재생성 비교, 웹 lint·typecheck, Vitest 2개 파일/5개 테스트.
- 중단: 기존 Next.js production build에서 Turbopack의 프로세스 생성·로컬 포트 바인딩이 `Operation not permitted`로 실패.
- 동일 검사를 권한 확장으로 다시 요청해 실행했으나 같은 포트 오류로 중단됐다. 전체 검사 통과로 표시하지 않는다.
- 전체 검사 순서상 뒤의 API test/build와 제품 Playwright E2E는 이번 실행에서 도달하지 못했다.
- 위 오류를 이유로 제품 설정·의존성·보안 규칙을 변경하지 않았다. 독립 시안은 Next.js 빌드 없이 정상 실행·브라우저 검토했다.

기존 `apps/api/bin/`과 이전 UI 리뷰 폴더는 보존했다. 제품 코드·API 계약·migration·의존성의 최종 diff는 없으며, 커밋·push·PR·배포는 실행하지 않았다.

### 이번에 실제 실행한 검사

- 파일: 실행·문서 9개와 캡처 14개만 복사했다. 캡처는 원본과 바이트가 동일하며 이미지 디코딩·모아보기 검사를 수행했다.
- 문서·자산: Markdown 링크, HTML의 CSS·JS·SVG 경로, CSS 참조 파일 존재 확인.
- JavaScript: `node --check`로 app.js, views.js, controller.js 문법 검사 통과 (Node 25.6.1, 별도 패키지 설치 없음).
- Chrome 데스크톱: 문제 탐색 → 소개 → 작성 → 검산 → 피드백 → 되묻기 → 수정 → 최종 리포트 → 내 학습의 기본 화면·주요 이동 통과.
- 입력: 빈 보고서 제출 차단, 보고서 예시 입력, 최초 보고서와 별도 검산 초안 안내 확인.
- 검산: S01 유지 판단·이유 저장, 미검토 3개 안내 확인 후 부분 제출, 입력한 이유가 피드백에 표시됨 확인.
- 조건 공개: 두 답변이 비어 있을 때 다음 단계 차단, 예시 답변 저장 이후에 새 조건 화면 진입 확인.
- 최종 제출: 수정 예시와 이유를 입력한 뒤 확인 대화상자로 제출, 최초·최종 보고서 구분과 내 학습의 완료 1건 표시 확인.
- 콘솔: 이번 탭에서 조회한 warning/error 0건.
- 서버 요청: HTML·CSS·JS와 명시된 favicon.svg는 모두 HTTP 200. 브라우저의 별도 /favicon.ico 요청은 404였으며 해당 파일은 HTML에서 참조하지 않는다. 명시 아이콘과 주요 화면 이동에는 영향이 없었고, 포함 범위 밖의 ICO 파일을 추가하지 않았다.
- 표시: 화면·문서에 **승인 전 디자인 시안 v0.1**, 가상 자료, 실제 AI 평가가 아니라는 안내 확인.
- Git: `git diff --check` 및 staged 파일 검사를 수행하고 디자인 자료 이외의 변경을 포함하지 않는다.

### 공개 경계와 이번 검증의 한계

가상 데이터와 모의 AI 응답을 사용하는 독립 프로토타입이다. 실제 API·DB·LLM 호출은 없다.
실행 파일에서 외부 요청 코드와 저장소 fixture import·비공개 정답 필드 참조가 발견되지 않았고,
텍스트의 키·토큰 패턴 검사와 캡처 육안 검토에서도 실제 비밀값은 발견되지 않았다.
사용자 보고서와 검산 초안은 별도 상태로 다루며, 후속 자료의 화면 공개는 단계 가드로 제한한다.
단, 가상 후속 자료는 정적 JS에 포함되므로 소스 열람까지 막는 보안 기능은 아니다.
실제 비공개 정답·미공개 자료는 이 코드에 넣지 않고 서버의 권한·단계 검증으로 관리해야 한다.

이번에는 모바일·새로고침 복원·모든 판단 조합을 다시 검사하지 않았다. 기존 기록을 새 실행 결과로 주장하지 않는다.
제품 소스·API 계약·migration·환경 설정을 변경하지 않았으므로 제품 `npm run check`, 실제 AI·로그인·DB 연결은 재실행하지 않았다.
GitHub CI는 로컬 검증에 포함되지 않는다. 디자인 승인·제품 기능 구현·배포 완료를 의미하지 않는다.
