# 디자인 기준

**상태: 학습 플랫폼 시안 v0.1을 제품 디자인 기준으로 승인 (2026-09-10).**
사용자가 기존 시안을 최종 기준으로 확정하고, 후속 개선은 구현 과정에서 반영하도록 요청했다.
이 승인은 시각·화면 구성 기준에 대한 승인이다. 시안의 가상 데이터·모의 AI 응답·제품 기능 완료를 승인한 것이 아니다.

## 고정 원본

[승인한 시안 원본](https://github.com/Corinbeom/Doezip/tree/966d6e681a101693b0cd5c9e88bfde3520344c00/docs/design/prototypes/learning-platform)
커밋 `966d6e681a101693b0cd5c9e88bfde3520344c00`, 기존 `feature/design-prototype`에 보존한다.
원본의 ‘승인 전’ 표기는 당시 상태 기록이다. 현재 승인 상태는 이 문서가 우선한다.
원본 JS는 가상 데이터와 모의 AI를 쓰는 독립 HTML 프로토타입이므로 제품 번들에 포함하지 않는다.
시안 전체·캡처·ZIP을 제품 브랜치에 중복 복사하지 않는다.

## 구현 기준과 적용 범위

- [화면 매핑](screens/README.md): 승인 화면과 실제 제품 경로.
- [디자인 토큰](tokens/README.md): 색상·서체·여백·반응형 기준.
- [상태 명세](states/README.md): API 로딩·빈값·오류·재시도·접근성.
- [이식 검증 기록](TASK_DESIGN_VALIDATION.md): 브랜치 의존성, 실행 결과, 남은 범위.

과제 목록·상세·로그인과 공통 화면 구성을 이식했다. F02b는 승인된 색상·패널 구성을 재사용해 공개 자료와 보고서 편집 작업 공간을 구현한다. F02c는 같은 화면에 최초 제출·읽기 전용 제출본을 추가한다. F04a는 안내 확인과 별도 초안 열람을 추가한다. 내 학습 대시보드의 현재 역할은 [P11 기록](../P11_LEARNING_DASHBOARD_BRAND.md)을 따른다. 실제 API의 데이터만 표시하고 계약에 없는 시간·자료 수·난이도를 만들지 않는다.
사용자 보고서·검산 초안·비공개 정답을 분리하고, 미공개 자료를 브라우저나 학습용 AI에 전달하지 않는다.

## 브랜드 자산

2026-09-18 사용자가 제공한 되짚 워드마크와 심볼을 제품 브랜드 자산으로 적용했다. 제품 헤더·푸터와 앱 아이콘의 실제 적용 위치 및 `/learn`과 `/tasks`의 화면 역할은 [P11 기록](../P11_LEARNING_DASHBOARD_BRAND.md)을 따른다. 원본 비율과 색을 유지하며 임의로 다시 그리거나 변형하지 않는다.

F04b 검토·인용 편집과 제출 잠금 상태는 기존 화면 안에 연결한다. 구현·검증 범위는 [F04b 기록](../F04B_CHALLENGE_REVIEW.md)을 따른다.

검산 편집과 평가 결과의 스타일 보완은 [F04c 기록](../F04C_CHALLENGE_UI.md)을 따른다. 기존 승인 토큰을 사용하며 평가 기능·모델 변경과 분리한다.

F03a는 기존 작성 화면에 승인된 토큰을 재사용한 AI 대화 패널을 추가한다. 로딩·전송·중지·실패·복원 및 320px 검증 범위는 [F03a 기록](../F03A_LEARNING_CHAT.md)을 따른다. 전체 채팅 시안 이식이나 후속 작성 단계 완료를 뜻하지 않는다.
