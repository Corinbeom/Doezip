# 승인 화면과 제품 경로

기준은 [디자인 원본](../README.md)의 고정 커밋이다.

| 시안 | 제품 경로 | 이번 적용 |
|---|---|---|
| 승인 토큰 기반 제품 랜딩 | / | 서비스 가치·학습 방식·보고서/구현 과제 소개와 내 학습 진입 |
| 승인 토큰 기반 내 학습 | /learn | 진행 중 기록 우선, 새 과제·훈련 방식 선택, 완료 기록 접기 |
| 01-explore-desktop / 14-explore-mobile | /tasks | 보고서·구현 통합 카탈로그, 유형 필터·태그·난도·예상 시간·반응형 |
| 02-detail-desktop | /tasks/{catalogId} | 과제 상황·완료 조건·제출물·훈련 방식 선택과 시작 |
| 로그인 | /login, /auth/callback | Google 인증 진입·오류·계정 연결 |
| 자료·보고서 작업 공간 | /sessions/{sessionId} | 공개 자료·줄 번호·보고서 편집·저장 상태, 모바일 한 열 |
| 나머지 학습 화면 | 후속 | 디자인 승인만 완료, 제품 기능 이식 미완료 |

과제 제목·설명·유형·태그·난도·예상 시간·버전은 공개 catalog API 데이터다. 승인 시안의 자료 개수처럼 계약에 없는 값은 복사하지 않는다. 로그인과 과제 시작은 실제 인증·API에 연결했다. UUID 기반 이전 과제 상세는 기존 기록 호환용이다.
장식용 SVG는 실제 측정치나 학습 결과를 표현하지 않도록 검토한 뒤 재사용한다.
