# 승인 화면과 제품 경로

기준은 [디자인 원본](../README.md)의 고정 커밋이다.

| 시안 | 제품 경로 | 이번 적용 |
|---|---|---|
| 01-explore-desktop / 14-explore-mobile | /tasks | 헤더·히어로·과제 카드·보조 안내·반응형 |
| 02-detail-desktop | /tasks/{taskId} | 설명 헤더·일러스트·설명 및 공개 루브릭·보조 안내 |
| 로그인 | /login, /auth/callback | Google 인증 진입·오류·계정 연결 |
| 자료·보고서 작업 공간 | /sessions/{sessionId} | 공개 자료·줄 번호·보고서 편집·저장 상태, 모바일 한 열 |
| 나머지 학습 화면 | 후속 | 디자인 승인만 완료, 제품 기능 이식 미완료 |

과제 제목·설명·루브릭·버전·발행 상태는 API 데이터다. 승인 시안의 제목·소요 시간·자료 개수는
현재 계약에 없거나 실제 과제 데이터와 다르므로 복사하지 않는다. 로그인과 과제 시작은 실제 인증·API에 연결했다. 내 학습 목록·제출 이후 화면은 후속이다.
장식용 SVG는 실제 측정치나 학습 결과를 표현하지 않도록 검토한 뒤 재사용한다.
