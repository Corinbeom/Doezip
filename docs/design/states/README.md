# 과제 조회 상태

| 상태 | 동작 |
|---|---|
| 로딩 | 과제 로딩 안내를 표시하며 데이터 성공으로 대체하지 않음 |
| 빈 목록 | 공개된 과제가 없다는 안내, 허위 카드 없음 |
| 네트워크 / 5xx 오류 | 명확한 실패 안내와 재시도, 실제 API를 다시 호출 |
| 400 / 404 상세 | 과제를 찾을 수 없다는 안내와 목록 복귀 |
| 정상 | DB의 제목·설명·공개 루브릭을 렌더링 |
| ARCHIVED 상세 | 보관 상태 표시, 새 학습 시작 동작 없음 |

상태를 색상만으로 구분하지 않는다. 로딩은 status, 실패는 alert로 알린다.
링크·버튼은 키보드로 접근하고 focus-visible을 제공한다. 장식 SVG는 접근성 트리에서 제외한다.
Markdown/HTML 입력은 실행하지 않으며 문자열은 React 텍스트로 렌더링한다.
